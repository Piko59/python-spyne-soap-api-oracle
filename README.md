# Python Spyne SOAP API with Oracle DB Integration

Bu proje, Python'da [Spyne](http://spyne.io/) kütüphanesi kullanılarak geliştirilmiş bir SOAP API örneğidir. API, bir iş ilanı ve başvuru yönetim sistemi için temel CRUD (Oluşturma, Okuma, Güncelleme, Silme) işlemlerini sağlar. Veri depolama için Oracle Veritabanı ile entegre çalışır ve istek sınırlaması için Upstash Redis kullanır.

## Özellikler

* **Kullanıcı Yönetimi:** Kayıt olma, giriş yapma, kullanıcı bilgilerini güncelleme ve silme.
* **İş İlanı Yönetimi:** İş ilanı oluşturma, güncelleme, silme ve listeleme.
* **Başvuru Yönetimi:** İş ilanlarına başvuru yapma, başvuruları güncelleme, silme ve listeleme.
* **Mülakat Yönetimi:** Mülakat planlama, güncelleme, silme ve listeleme.
* **SOAP Protokolü:** Spyne kütüphanesi ile SOAP 1.1 protokolünü destekler.
* **Veritabanı Entegrasyonu:** Oracle veritabanı ile etkileşim için `oracledb` kütüphanesini kullanır.
* **Rate Limiting:** Upstash Redis kullanarak API isteklerini sınırlar.
* **Docker Desteği:** Kolay kurulum ve dağıtım için Docker kullanır[cite: 1].

## Teknolojiler

## Kurulum

### Ön Koşullar

* Docker ve Docker Compose yüklü olmalıdır.
* Çalışan bir Oracle Veritabanı örneği (örneğin, Oracle XE).
* Bir Upstash Redis örneği ve bağlantı bilgileri.

### Adımlar

1.  **Depoyu Klonlayın:**
    ```bash
    git clone [https://github.com/kullanici_adiniz/python-spyne-soap-api-oracle.git](https://github.com/kullanici_adiniz/python-spyne-soap-api-oracle.git)
    cd python-spyne-soap-api-oracle
    ```

2.  **Oracle Ağı:**
    Eğer harici bir Oracle veritabanı ağı kullanıyorsanız (`oracle-network` gibi [cite: 1]), bu ağın mevcut olduğundan emin olun veya oluşturun:
    ```bash
    docker network create oracle-network
    ```
    Oracle veritabanı konteynerinizin de bu ağa bağlı olduğundan emin olun.

3.  **Ortam Değişkenleri:**
    `docker-compose.yaml` dosyasını [cite: 1] veya sistem ortam değişkenlerini kendi Oracle DB ve Upstash Redis bilgilerinizle güncelleyin:
    * `ORACLE_USER`: Oracle kullanıcı adınız[cite: 1].
    * `ORACLE_PASSWORD`: Oracle şifreniz[cite: 1].
    * `ORACLE_DSN`: Oracle DSN (Data Source Name) bilginiz (örneğin, `your_oracle_host:1521/your_service_name`)[cite: 1].
    * (Gerekirse `soap_api.py` içinde) Upstash Redis URL ve Token. *Not: Güvenlik nedeniyle hassas bilgileri doğrudan koda yazmak yerine ortam değişkenleri veya yapılandırma dosyaları kullanmak daha iyidir.*

4.  **Veritabanı Tablolarını Oluşturun:**
    API'nin kullanacağı Oracle veritabanı tablolarını (USERACCOUNTS, JOBS, APPLICATIONS, INTERVIEWS) oluşturmanız gerekecektir. Örnek SQL komutları:
    ```sql
    -- Bu komutları kendi şemanıza göre uyarlayın
    CREATE TABLE USERACCOUNTS (
        USER_ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
        USERNAME VARCHAR2(255) UNIQUE NOT NULL,
        PASSWORD VARCHAR2(255) NOT NULL,
        ROLE VARCHAR2(50)
    );

    CREATE TABLE JOBS (
        JOB_ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
        TITLE VARCHAR2(255) NOT NULL,
        DESCRIPTION CLOB,
        DEPARTMENT VARCHAR2(255)
    );

    CREATE TABLE APPLICATIONS (
        APPLICATION_ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
        USER_ID NUMBER NOT NULL,
        JOB_ID NUMBER NOT NULL,
        STATUS VARCHAR2(50),
        FOREIGN KEY (USER_ID) REFERENCES USERACCOUNTS(USER_ID) ON DELETE CASCADE,
        FOREIGN KEY (JOB_ID) REFERENCES JOBS(JOB_ID) ON DELETE CASCADE
    );

    CREATE TABLE INTERVIEWS (
        INTERVIEW_ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
        USER_ID NUMBER NOT NULL,
        JOB_ID NUMBER NOT NULL,
        INTERVIEW_DATE DATE,
        INTERVIEW_RESULT VARCHAR2(255),
        FOREIGN KEY (USER_ID) REFERENCES USERACCOUNTS(USER_ID) ON DELETE CASCADE,
        FOREIGN KEY (JOB_ID) REFERENCES JOBS(JOB_ID) ON DELETE CASCADE
    );
    ```

5.  **Docker ile Çalıştırın:**
    ```bash
    docker-compose up --build
    ```
    API, `http://localhost:8000` adresinde çalışmaya başlayacaktır[cite: 1].

## API Kullanımı

SOAP istemcinizle (örneğin SoapUI, Postman veya Python'daki `zeep` kütüphanesi) aşağıdaki WSDL adresine bağlanarak API metodlarını çağırabilirsiniz:

`http://localhost:8000/?wsdl`

Mevcut servisler ve metodlar şunlardır:

* **UserService:** `register`, `login`, `update_user`, `delete_user`
* **JobService:** `create_job`, `update_job`, `delete_job`, `get_jobs`
* **ApplicationService:** `apply_for_job`, `update_application`, `delete_application`, `get_applications`
* **InterviewService:** `schedule_interview`, `update_interview`, `delete_interview`, `get_interviews`

**Not:** Güncelleme ve silme işlemleri gibi bazı metodlar rate limiting uygulamasına tabidir.
